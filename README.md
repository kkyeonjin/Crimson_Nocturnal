# Crimson Nocturnal
<img width="1920" height="1080" alt="Group 126" src="https://github.com/user-attachments/assets/7701a45e-a0de-42dc-990d-a3ba5c0ed611" />

**3D Combo Action RPG** - UE5 solo project (Oct 2025–Feb 2026)

## Game Overview
Vampire combos drain enemy blood to fill BP gauge, unleashing skill tree ultimates

**Demo**: [Link to video](https://drive.google.com/file/d/1C0aNod3FDEZ_8c9uvgtJB1g2_6Zl08j3/view?usp=sharing)

## Overall Architecture
<img width="963" height="646" alt="image" src="https://github.com/user-attachments/assets/bb76c813-619b-4b18-bc6c-587dcc923603" />
Component-based with delegates/interfaces for modularity.

## Key Tech Features
- **Delegates**: Loose coupling (OnDamage → HUD)
- **Decentralized AI**: Per-enemy Blackboards + BT nodes for independent behavior
- **AnimMontage/Notify**: Combo precision + VFX
- **DataTables**: Balanced enemy stats
